Home Assistant & UniFi Protect Integration Guide

Configure automated face recognition and training pipelines with your existing smart home setup.

1. UniFi Protect Auto-Training Webhook

When your UniFi camera identifies a known face, trigger a webhook call to automatically train and refine the model with the new snapshot. 

# Home Assistant Automation Action
service: rest_command.feed_protect_face
# Or standard HTTP webhook action:
action:
  - service: http.post # Or shell_command / rest_command
    data:
      url: "http://<DOCKER_HOST>:8000/api/v1/protect/webhook"
      method: "POST"
      payload: >
        {
          "person_name": "{{ trigger.json.triggers[0].value }}",
          "snapshot": "{{ trigger.json.thumbnail }}",
          "camera_id": "{{ trigger.json.triggers[0].sourceEvent.camera }}",
          "event_id": "{{ trigger.json.triggers[0].eventId }}"
        }

2. General Classification Endpoint

Send any base64 snapshot to identify who is at the door: 

curl -X POST http://<DOCKER_HOST>:8000/api/v1/recognize \
  -H "Content-Type: application/json" \
  -d '{
    "image": "data:image/jpeg;base64,...",
    "min_confidence": 0.50,
    "save_unrecognized": true
  }'

Detection & Recognition

Model parameters & matching sensitivity
0.50
Minimum confidence required for the InsightFace detector to register a face bounding box.
0.45
Cosine similarity threshold (0.0 to 1.0) above which a face is classified as a known household member.
Input size for the ONNX detection model. 320 is recommended for low latency real-time streaming.
Limits embeddings per person to prevent database bloat while maintaining high accuracy.
🔔

Notification & Alert Thresholds

Rules for outgoing Webhook & MQTT alerts
0.55
Minimum similarity required before firing an outgoing webhook or MQTT message. Prevents marginal matches from triggering false home automation alerts.
When enabled, strangers and unrecognized visitors will also trigger outgoing notifications.
0.60
Filters out low-confidence false face detections (e.g. shadows, objects) from spamming unknown visitor alerts.
Number of seconds to wait before repeating an alert for the same person while they remain in frame.

RTSP Video Ingestion

Live RTSP/RTSPS camera stream source
Background thread captures and classifies faces from your RTSP camera feed in real time.
Compatible with UniFi Protect RTSP/RTSPS feeds, Reolink, Wyze (Docker-Wyze-Bridge), etc.
Target endpoint to receive POST events containing face matches, bounding boxes, and crop thumbnails.
When enabled, outgoing webhooks are strictly dispatched for recognized household members and suppressed for strangers/unknown faces.
